Open-source beta

Get VidStow

v0.1.0-beta.1 is a macOS Apple Silicon preview. The recommended install is VidStow’s Homebrew tap — the cask brings FFmpeg along and handles the unsigned-beta caveats. The DMG and a source build remain alternatives.

$brew tap vidstow/tap $brew install --cask vidstow

FFmpeg and signing depend on the install path. The cask installs FFmpeg and FFprobe and, after verifying the release checksums, removes macOS quarantine so the ad-hoc-signed app opens normally. With the DMG — which is not notarized — you install FFmpeg yourself (for example, brew install ffmpeg) and open the app with right-click Open on first launch.

Questions

Is VidStow free?

Yes. The full app is free and Apache 2.0 licensed. An optional $5 contribution supports signing, testing, and continued development; it does not unlock features.

Does VidStow upload videos to its own server?

No. There is no VidStow conversion or storage service. The desktop app works locally while contacting the services needed for the download.

Can I download a prebuilt app?

Yes, for macOS on Apple Silicon. The recommended install is the Homebrew cask: it installs FFmpeg and FFprobe, verifies the release checksums, and removes macOS quarantine so the ad-hoc-signed app launches. You can also download the DMG and open it with right-click Open on first launch. Windows, Linux, and Intel Mac packages are outside this beta; those users can build from source without a support promise.

Which links are supported?

The beta supports public, on-demand YouTube video, Short, and playlist URLs. For now, it does not expose channels, search, live streams, authenticated media, or other sites.

What can I choose before downloading?

For one video or Short, VidStow shows the available curated video and audio outputs. For a playlist, you can select available entries, apply a position range, search the list, and choose a shared video-quality cap or audio policy before adding the collection.

Do I need FFmpeg?

Not with Homebrew — the cask installs FFmpeg and FFprobe for you. If you use the DMG, VidStow needs an installed pair for stream merging and MP3 conversion, detected on your PATH, in Homebrew’s default prefixes, or via a pair you choose; brew install ffmpeg covers it.

How do I update VidStow?

There is no in-app updater yet. With Homebrew, run brew update && brew upgrade --cask vidstow. If you installed from the DMG, download the next release and replace the app in Applications.

What am I allowed to download?

Only videos you have permission to save — your own uploads, openly licensed material, or content you otherwise have the rights to keep. Please follow YouTube’s Terms of Service and applicable copyright law.

Where do I report a problem?

Use GitHub Issues and include the privacy-safe diagnostics from VidStow Settings when relevant.
